# El Roble Eventos – Sistema de Administración de Eventos

El Roble Eventos nació con la idea de **digitalizar y simplificar la gestión de un centro de convenciones**, que incluye un salón y una quinta con alberca.  
El objetivo era que los administradores y empleados pudieran manejar todos los detalles de los eventos de manera centralizada y eficiente.

---

## 🗓️ Gestión interna de eventos

El sistema permite que los empleados y administradores:

- Vean su **calendario de eventos** en tiempo real.
- Consulten los **consumibles necesarios para cada evento**.
- Revisen los **servicios solicitados**, los horarios y el costo de cada evento.
- Gestionen pagos y controlen la logística de manera clara y organizada.

En resumen, es como un mini CRM enfocado en la operación del centro de eventos, donde todo está documentado y accesible para quienes gestionan el lugar.

---

## 🌐 Interacción con los clientes

El sistema también incluye una **landing page** pensada para los clientes:

- Permite ver los **servicios disponibles** y fotos de los espacios.
- Permite hacer **cotizaciones** de manera directa:
  - Consultar fechas disponibles.
  - Ver el costo de alquilar el espacio o servicios adicionales.
  - Solicitar servicios específicos para su evento.

El administrador tiene control total de estas solicitudes, pudiendo aprobarlas, ajustar detalles y mantener la información actualizada.

---

## 🔧 Tecnologías utilizadas

Para este proyecto decidí mantenerlo **simple y eficiente**, usando únicamente tecnologías maduras de Laravel:

- **Backend**: Laravel puro
- **Frontend**: Blade para las vistas
- Base de datos MySQL (gestionada desde Laravel Eloquent)

Esta arquitectura permitió que el sistema fuera **ligero, rápido y fácil de mantener**, ideal para un entorno donde la prioridad es la operativa diaria y la gestión de eventos sin complicaciones.

---

## 🚀 Conclusión

El Roble Eventos es un **sistema completo de administración para centros de eventos**, que combina eficiencia interna con interacción directa para los clientes.  
Desde la gestión de consumibles y servicios hasta la cotización online, todo está pensado para que los administradores puedan concentrarse en brindar la mejor experiencia a los clientes, mientras el sistema se encarga de organizar y centralizar la información.
